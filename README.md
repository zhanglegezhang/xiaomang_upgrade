# 小蟒通用升级工具

小蟒同学在线升级失败时的独立升级入口。工具版本 1.0，支持标准便携版 **2.6 起、结构兼容的 2.x 升级**。

## 下载与使用

1. 点击 **Code → Download ZIP**，完整解压到旧小蟒目录之外。
2. 从[小蟒正式发布页](https://github.com/zhanglegezhang/xiaomang/releases)下载目标版本的使用包 ZIP，不要解压该使用包。
3. 保存并关闭本地日记、输入法设置，结束录音和录屏。
4. 双击本仓库根目录的 **Upgrade.cmd**，选择旧版 `xiaomang.exe`、目标使用包，填写对应发布标签（例如 `v2.7-20261017`）。
5. 等待官方校验、完整备份、替换与启动检查完成。

仓库中的 PowerShell 脚本既是源码也是可运行工具，无需编译、安装 SDK 或输入法组件。需要 Windows PowerShell 5.1，并能联网访问 GitHub 核验官方包。请下载整个仓库，不要只下载一个脚本。

## 数据与恢复

- 未安装输入法且无数据：跳过输入法备份。
- 有输入法残留数据但缺组件：原样备份，不调用组件转换，不因此阻止升级。
- 已下载的可选组件、个人设置和数据保留；不重新注册输入法或收藏菜单。
- 完整旧目录、原始输入法数据和升级日志保存在 `%LOCALAPPDATA%\XiaomangUpdates\universal-随机编号`。备份含个人数据，**不要上传到 GitHub**。
- 文件占用、备份校验失败时停止；替换或启动失败时尝试恢复旧程序。请勿在升级期间强制结束或关机。

## 限制

不支持降级、同版本覆盖、跨大版本、自定义 `PersonalPath.cfg`、网络目录或链接目录。未来版本改变目录或数据结构时可能需要新版工具。

启动检查仅确认进程持续运行 10 秒，不能保证所有功能正常；新版本启动后自行修改的数据不保证自动回退，完整旧数据备份仍保留。断电或强制结束可能需要人工恢复。完整备份耗时和空间取决于实际数据量。

## 验证范围

已验证包结构、官方 SHA256、版本方向、危险路径和重复文件拒绝；文件占用、启动失败回滚；无组件、有残留数据、已有组件三种模拟升级流程。真实 2.7 官方包校验通过。2.8→2.9 仅使用模拟版本验证流程，未验证未来真实版本；未在干净系统或其他物理电脑完成测试。

## 开发与许可

直接编辑 `Upgrade.ps1`、`Core.ps1`、`install.ps1` 即可继续开发。`Upgrade.cmd` 是启动入口，详细说明见 [使用说明.txt](使用说明.txt)。不依赖原工程目录或构建脚本。
